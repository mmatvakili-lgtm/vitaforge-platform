# ADR-0004 — سیاست آفلاین (حل CON-002)

| فیلد | مقدار |
|---|---|
| Status | Accepted (با feature flag) |
| Date | 2026-11-07 |
| Owner | Architect |
| Related Decisions | DEC-004، DEC-122، DEC-125 |
| Related Documents | DOC-03، DOC-20 |

**مسئله:** تست ۱۴ (قطع اینترنت هنگام ثبت) در برابر ممنوعیت ذخیره آفلاین داده حساس.
**گزینه‌ها:** (A) هیچ ذخیره آفلاینی؛ (B) فقط داده غیرحساس تمرین با رمزنگاری سمت کلاینت.
**انتخاب:** B، پشت feature flag `offline_workout_log` (پیش‌فرض خاموش تا تأیید بازبینی امنیتی سند 15). در حالت خاموش: پیام صریح «ذخیره نشد».
**قاعده:** داده درد/علائم/سلامت هرگز آفلاین؛ PWA فقط Shell و محتوای عمومی غیرحساس را کش می‌کند؛ خروج از حساب/ابطال نشست داده آفلاین را پاک می‌کند.
**ریسک:** مدیریت کلید/از دست رفتن داده؛ ASM-010.
