## 1. اصول
- تغذیه **اختیاری** است؛ غیرفعال‌بودن تمرین را مختل نمی‌کند (FR-NUT-001). ماژول `nutrition` در MVP فقط Interface/Feature flag `nutrition_enabled=false` دارد.
- همه محاسبات «تخمین» و قابل بازبینی؛ هر خروجی با روش و منبع.
- از Safety Core عبور می‌کند (`context_type=nutrition`).
- هیچ داده/قیمت/ارزش غذایی جعلی؛ بدون منبع = «ناموجود/تخمینی».

## 2. ورودی‌ها و خروجی‌ها
ورودی (سند مادر §14): هدف، سن، قد/وزن، فعالیت، ترجیح، آلرژی، عدم تحمل، محدودیت پزشکی، فرهنگ غذایی، بودجه، کشور، توان آشپزی، تعداد وعده.
خروجی: تخمین انرژی/ماکرو/فیبر/آب (راهنما)، وعده‌ها، دستور، سهم، فهرست خرید، جایگزین، هزینه تخمینی (فقط با داده قیمت منبع‌دار).

## 3. مراحل
```
N0  Eligibility gate (Safety Core): out-of-scope، اختلال خوردن (DEC-117)، بارداری، بیماری → BLOCK/ارجاع
N1  Energy estimate: BMR (Mifflin–St Jeor — Unverified تا ثبت منبع) × activity factor (config) = TDEE تخمینی
N2  Goal adjustment: فقط درون [کف، سقف] ایمنی (EXP-006؛ مقادیر تعریف‌نشده → غیرفعال‌سازی کاهش/افزایش خودکار)
N3  Macro split: بازه‌ها از config بازبینی‌شده (EXP-006)
N4  Meal plan builder: انتخاب از `foods/recipes` با فیلتر سخت آلرژن/عدم‌تحمل/الگوی غذایی/بودجه
N5  Validate: Σ ماکرو ≈ هدف ± tolerance؛ آلرژن=∅؛ Safety post-pass
N6  Shopping list + cost estimate (price rows با منبع/تاریخ/منطقه؛ وگرنه «تخمینی/ناموجود»)
```
## 4. قواعد ایمنی ساختاری (قابل پیاده‌سازی بدون تأیید بالینی)
| ID | قاعده |
|---|---|
| NUT-R01 | آلرژی = محدودیت سخت؛ هر غذا/دستور با آلرژن کاربر مسدود (حتی «ردپا» اگر داده باشد) |
| NUT-R02 | نشانه خطر اختلال خوردن (DEC-117) ← تغذیه محدودکننده غیرفعال + ارجاع |
| NUT-R03 | هدف کاهش/افزایش وزن افراطی (فراتر از سقف config بازبینی‌شده) رد؛ تا تعریف سقف: بدون هدف عددی کاهش/افزایش |
| NUT-R04 | رژیم درمانی بیماری بدون متخصص تولید نمی‌شود |
| NUT-R05 | غذا بدون منبع/تاریخ در برنامه نمی‌آید |
| NUT-R06 | مکمل: فقط محتوای آموزشی منبع‌دار؛ توصیه قطعی ممنوع (EXP-007) |
| NUT-R07 | قیمت بدون منبع/تاریخ/منطقه نمایش داده نشود |
## 5. جایگزینی غذا
امتیاز بر پایه: ارزش غذایی (ماکرو نزدیک)، آلرژن (سخت)، هدف، ترجیح، هزینه، دسترسی منطقه‌ای، محدودیت پزشکی. «صرفاً کالری مشابه» کافی نیست. نبود جایگزین ← اعلام.
## 6. داده و حاکمیت
`FoodDataSource` Port (DEC-106)؛ هر غذا: منبع، تاریخ، مجوز؛ بازبینی `nutrition_reviewer`؛ نسخه‌بندی؛ پایگاه آزمایشی `SAMPLE_UNREVIEWED` ممنوع در Production.
