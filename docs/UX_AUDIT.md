# ممیزی تجربه‌ی کاربری (جریان‌ها)

> روش: خواندن کد صفحه‌ها و جریان‌ها + بازخورد اسکرین‌شات‌های مالک. هنوز مرورگر واقعی توسط دستیار اجرا نشده؛ هر مورد «پیاده‌شده» باید با چشم مالک تأیید شود.

## ۱. ثبت‌نام → تأیید → ورود
| یافته | وضعیت |
|---|---|
| پس از ورود، کاربر به «برنامه» می‌رفت نه «امروز» (مرکز تصمیم) | **اصلاح شد**: ورود به «امروز» |
| صفحه‌ی ورود سه لینک پشت‌سرهم بدون سلسله‌مراتب دارد | **اصلاح شد** |
| پیام خطای ورودِ حساب تأییدنشده راهنمای مستقیم «تأیید حساب» ندارد | **اصلاح شد** (راهنما پس از ۴۰۱؛ سرور عمداً علت را فاش نمی‌کند) |
| رنگ لینک‌ها پیش‌فرض مرورگر (بنفش) بود | **اصلاح شد** |
| دکمه‌ی نمایش گذرواژه روی نقطه‌ها می‌افتاد | **اصلاح شد** |

## ۲. تلگرام
| یافته | وضعیت |
|---|---|
| کاربر واردشده هیچ راهی برای اتصال تلگرام نداشت | **اصلاح شد**: API-TG-004، مراحل سه‌گانه، تشخیص خودکار |
| یادآوری اتصال در «امروز» وجود نداشت | **اصلاح شد** (قابل بستن) |
| قطع اتصال تلگرام از پروفایل ممکن نیست | باز (نیازمند endpoint و تصمیم امنیتی) |

## ۳. تمرین (هسته‌ی محصول)
| یافته | وضعیت |
|---|---|
| پس از هر ست، تکرار و وزن پاک می‌شد و کاربر باید دوباره تایپ می‌کرد | **اصلاح شد**: مقدار قبلی می‌ماند؛ تکرار هدف برای حرکت جدید پر می‌شود |
| ورود عدد با کیبورد در باشگاه سخت است | **اصلاح شد**: دکمه‌های −/+ بزرگ و انتخاب RPE با چیپ |
| «سختی» پایان جلسه هنوز ورودی متنی است | **اصلاح شد** |
| نبود حالت تمام‌صفحه‌ی تمرین (یک ست، یک تمرکز) | **بخشی اصلاح شد**: دکمه‌های چسبیده به پایین و تیتر درشت؛ تمام‌صفحه‌ی واقعی باز است |
