# ممیزی تجربه‌ی کاربری (جریان‌ها)

> روش: خواندن کد صفحه‌ها و جریان‌ها + بازخورد اسکرین‌شات‌های مالک. هنوز مرورگر واقعی توسط دستیار اجرا نشده؛ هر مورد «پیاده‌شده» باید با چشم مالک تأیید شود.

## ۱. ثبت‌نام → تأیید → ورود
| یافته | وضعیت |
|---|---|
| پس از ورود، کاربر به «برنامه» می‌رفت نه «امروز» (مرکز تصمیم) | **اصلاح شد**: ورود به «امروز» |
| صفحه‌ی ورود سه لینک پشت‌سرهم بدون سلسله‌مراتب دارد | **اصلاح شد** |
| پیام خطای ورودِ حساب تأییدنشده راهنمای مستقیم «تأیید حساب» ندارد | **اصلاح شد** (راهنما پس از ۴۰۱؛ سرور عمداً علت را فاش نمی‌کند) |
| رنگ لینک‌ها پیش‌فرض مرورگر (بنفش) بود | **اصلاح شد** |
| دکمه‌ی نمایش گذرواژه روی نقطه‌ها می‌افتاد | **اصلاح شد** |

## ۲. تلگرام
| یافته | وضعیت |
|---|---|
| کاربر واردشده هیچ راهی برای اتصال تلگرام نداشت | **اصلاح شد**: API-TG-004، مراحل سه‌گانه، تشخیص خودکار |
| یادآوری اتصال در «امروز» وجود نداشت | **اصلاح شد** (قابل بستن) |
| قطع اتصال تلگرام از پروفایل ممکن نیست | **اصلاح شد**: API-TG-005؛ تأیید حساب دست‌نخورده می‌ماند |

## ۳. تمرین (هسته‌ی محصول)
| یافته | وضعیت |
|---|---|
| پس از هر ست، تکرار و وزن پاک می‌شد و کاربر باید دوباره تایپ می‌کرد | **اصلاح شد**: مقدار قبلی می‌ماند؛ تکرار هدف برای حرکت جدید پر می‌شود |
| ورود عدد با کیبورد در باشگاه سخت است | **اصلاح شد**: دکمه‌های −/+ بزرگ و انتخاب RPE با چیپ |
| «سختی» پایان جلسه هنوز ورودی متنی است | **اصلاح شد** |
| نبود حالت تمام‌صفحه‌ی تمرین (یک ست، یک تمرکز) | **بخشی اصلاح شد**: دکمه‌های چسبیده به پایین و تیتر درشت؛ تمام‌صفحه‌ی واقعی باز است |

## ۶. بخش‌های بررسی‌نشده‌ی عمیق
Onboarding (۷ مرحله)، ارزیابی حرکتی، لاگ تغذیه و لیست خرید، پنل مدیر: فقط ظاهر لایه‌ی طراحی ارتقا یافته؛ جریان‌هایشان هنوز ممیزی کامل نشده‌اند.

## ۷. نکته‌های مرجع‌های طراحی و اجرای آن‌ها
منابع: [Laws of UX](https://lawsofux.com/)، [Apple HIG — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)، ده اصل قابلیت‌استفاده‌ی Nielsen Norman (متن آن در این نشست قابل خواندن نبود؛ از دانش عمومی استفاده شد).

| اصل | یافته در سایت | وضعیت |
|---|---|---|
| WCAG AA / HIG: کنتراست ۴٫۵:۱ | متن سفید روی نارنجی ۳٫۱:۱ بود (حالت فعالِ تب‌ها و چیپ‌ها) | **اصلاح شد** + تست دائمی `contrast.test.ts` برای جفت‌رنگ‌های اصلی |
| HIG: اطلاعات فقط با رنگ منتقل نشود | نقطه‌های هفته فقط رنگ بودند | **اصلاح شد**: علامت ✓ |
| HIG/NN/g: دسترسی با صفحه‌کلید | پرش به محتوا نبود | **اصلاح شد** |
| Postel: ورودی را آزادانه بپذیر | ارقام فارسی در تکرار/وزن | **اصلاح شد** (نرمال‌سازی در Stepper) |
| Zeigarnik: کار نیمه‌تمام دیده شود | تمرین نیمه‌کاره در «امروز» نبود | **اصلاح شد**: کارت «ادامه» |
| Doherty (≈۴۰۰ms) | انتقال صفحه‌ها | رعایت شد (نوار پیشرفت + ورود ۳۲۰ms) |
| HIG: کاهش حرکت | حرکت‌های x/y و بلور | بلور حذف شد؛ با تنظیم کاهش حرکت همه خاموش‌اند |
| HIG: هدف لمسی ۴۴pt | کنترل‌های اصلی | از قبل رعایت می‌شد |
| Hick/Miller: انتخاب‌های کمتر | منوی «بیشتر» | گروه‌بندی شد |
| بزرگ‌نمایی متن تا ۲۰۰٪ بدون شکستن چیدمان | بررسی نشده | باز (نیازمند مرورگر واقعی) |
